# 来财答题挑战

《奥星热浪》「来财行动」答题宝箱的题目试做页，当前共 610 题，只包含题库工具中已通过的题目。

**打开即用：<https://nier110000.github.io/laicai-quiz/>**

## 怎么玩

1. 点「开始挑战」，填一个名字（可以重名）；
2. 每轮从题库随机抽 10 题，点选项作答，答完显示正确率；
3. 每题下面可以写一句反馈，点击「确认反馈」后才上传；答完之后也可补写并确认；
4. 答完一轮，右侧会出现所有人的答题记录、易错题、点赞榜和反馈；识图题只看图片，看不到选项名称。

可以按题目分类筛选：教程、知识、梗文字、光仔识图、道具识图、梗识图。

## 说明

- 整页是一个单文件，图片已内嵌，手机上也能直接打开；
- 成绩和反馈会上传，所有人共享，所以在自己的电脑上答题，别人也能看到；
- 答题记录只用来改进题目，不做任何其他用途；
- 服务器连不上时照样能答题，只是看不到别人的记录；
- 错题本存在自己的浏览器里，换电脑不会同步。
